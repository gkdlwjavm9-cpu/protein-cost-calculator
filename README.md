# 단백질 단가 계산기 (마이크로 웹툴)

`index.html` **한 파일**로 끝나는 1페이지 도구입니다. 외부 라이브러리·CDN·유료 API를 쓰지 않아 인터넷 없이도 그대로 동작합니다.

## 무엇을 하나
- 식품의 가격·총중량·단백질(g/100g)·열량을 입력하면
  - 100g당 가격
  - **1g 단백질당 원가** (핵심 지표 — 이게 낮을수록 단백질을 싸게 사는 것)
  - 단백질 열량비(그 식품 열량 중 단백질 비율)
  - 하루 목표 단백질을 그 식품으로 채울 때의 비용·중량·열량
  을 계산해 가장 싼 순서로 정렬합니다.
- 예시 26종(닭가슴살·우유·두부·그릭요거트·쉐이크 등)을 한 번에 불러올 수 있어 빈 화면에서 시작하지 않습니다.
- 값은 브라우저 localStorage에만 저장되고 서버로 전송되지 않습니다. 표 복사(엑셀 붙여넣기) 지원.
- 다크모드 대응, 모바일 레이아웃.

## 검증
```bash
python3 tests/test_tool.py     # 25개 항목 통과 (quickjs로 index.html의 JS를 실제 실행)
```
`index.html` 안의 `/* PURE_LOGIC_START */ ~ /* PURE_LOGIC_END */` 구간이 DOM과 무관한 계산부이며, 테스트가 이 구간만 떼어내 실행합니다.

## 배포 방법 (무료)
1. **GitHub Pages**: 저장소 만들고 `index.html` 올린 뒤 Settings → Pages → main 브랜치 지정. 주소는 `아이디.github.io/저장소명`.
2. **Netlify**: app.netlify.com → "Add new site" → 폴더를 드래그. 커스텀 도메인도 무료로 붙일 수 있습니다.
3. 도메인을 사고 싶으면 `.com` 연 1~2만 원대.

## 수익 경로 3가지
1. **애드센스** — 페이지에 `광고 영역` 자리(주석 처리된 `.adslot`)가 이미 있습니다. 애드센스 승인 후 코드만 넣으면 됩니다. 단, 도구 페이지 단독으로는 트래픽이 적어 초기 수익은 미미합니다.
2. **리드 마그넷** — 상단에 "이 계산을 4주치 식단표로 자동화한 엑셀" 링크를 걸어 `디지털상품-1호`로 유입. 도구는 무료, 파일은 유료라는 구조가 가장 현실적입니다.
3. **검색 유입 확장** — 지금은 "단백질 단가"라는 좁은 키워드입니다. 아래 확장 아이디어를 붙이면 페이지 수를 늘릴 수 있습니다.
